---

## ✨ Features

- **🌌 3D Interactive Particle Constellation**: Responsive HTML5 3D canvas mesh with real-time mouse/touch parallax.
- **🎴 3D Perspective Tilt**: Card physics with dynamic specular lighting glare on profile and project cards.
- **💻 Interactive CLI Terminal (`Ctrl+K`)**: Built-in developer command line interface supporting custom commands (`help`, `about`, `skills`, `projects`, `education`, `contact`, `theme`, `confetti`).
- **🛡️ Real-Time Validated Contact Form**: Form validation connected with [Formspree](https://formspree.io) to forward inquiries directly to Gmail with zero backend maintenance.
- **📱 100% Mobile Responsive**: Fluid layout tested across mobile, tablet, and desktop viewports.
- **🌓 Dark & Light Mode**: Seamless theme switcher with persistent local storage.
- **📄 Instant Resume PDF Access**: Direct integrated PDF viewer and download trigger.

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Tailwind CSS v4, Lucide React, Canvas Confetti
- **Tooling**: Vite 8, PostCSS, ESLint
- **Forms & Email**: Formspree API
- **Deployment**: Vercel / Firebase Hosting / Netlify

## 💻 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/ashutoshprajapat29/portfolio.git

# Navigate to project folder
cd portfolio

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
